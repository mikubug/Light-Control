# Light-Control

Light-Control 是一个面向教室、会议室及公共空间场景的智能灯光控制方案，目标是让灯光控制更可靠、更灵活，并能够在网络波动或设备异常时自动恢复正常状态。

它并不只是一个简单的“开关控制器”，而是一套用于管理多路照明设备、支持本地操作、远程控制和状态自愈的智能控制系统。项目的设计重点在于“稳定性、可维护性和实际使用体验”，尤其适合需要长期稳定运行、具备多区域灯光管理需求的场景。

## 项目定位

这套项目以“安全、稳定、可远程控制”为核心目标，解决日常照明管理中常见的问题：

- 手动控制不够高效，尤其在教室或会议场景中常需要统一开关。
- 设备依赖网络时容易出现断线、重连、状态异常等情况。
- 现场操作和远程控制需要保持一致，避免平台状态与实际设备状态不一致。
- 灯光设备需要具备一定的自恢复能力，减少人工巡检与维护成本。

因此，项目不仅实现灯光的开/关动作，还兼顾了状态同步、断线重连、异常恢复、升级维护等实际使用中的关键能力。

## 主要功能

### 1. 多路灯光控制

系统支持多路照明回路独立管理，适合教室、会议室和会场中不同区域、不同灯组的分组控制。用户可以通过集中控制方式实现：

- 单路开关
- 多路联动
- 全开 / 全关
- 按需状态切换

这使得灯光控制更符合真实使用场景，而不仅限于单一开关逻辑。

### 2. 本地与远程双重控制

本项目兼顾现场和远程控制两种方式：

- 现场按键操作：适合日常本地使用，控制响应直接且稳定。
- 远程信号控制：设备可接入统一控制平台，通过消息通讯进行远程调度。

这样无论是在教室中现场切换，还是在后台统一进行设备管理，都可以保持一致的控制体验。

### 3. 状态同步与实时反馈

系统会持续维护灯光状态，并在关键时刻进行状态反馈与重发，减少“平台显示状态”和“设备真实状态”偏差的问题。这样可以降低异常情况下的误判风险，并提升系统可靠性。

### 4. 自动恢复与自愈能力

这是本项目最重要的特点之一。设备在出现异常时，并不会直接失控，而是会尝试：

- 自动重连网络
- 切换备用通道
- 恢复在线状态
- 对异常状态进行重试和修正
- 一定条件下自动进入安全模式，避免继续工作在不可靠状态

这些机制让设备更适合长期运行环境，尤其适合教室等不能频繁维护的场景。

### 5. 网络和设备稳定性保障

项目内置了对网络断线、异常重启、资源不足等情况的处理机制，包括：

- 断线后自动重试
- 网络不稳定时自动选择更可靠路径
- 资源压力较高时进行清理和恢复
- 关键任务优先保障运行稳定

这意味着系统在真实环境中比传统“简单控制器”更能承受网络波动、设备偶发故障等情况。

### 6. OTA 升级支持

项目支持在线升级功能，便于后续修复问题、增加功能和优化表现。升级机制会保持一定的安全保护，避免在异常情况下直接覆盖关键逻辑，并提供回滚能力，以增强系统稳定性。

### 7. 日志与诊断能力

系统具备日志记录和事件追踪能力，便于后续排查：

- 连接状态变化
- 设备重启与恢复
- 升级情况
- 异常事件与修复过程

这使得日常运维、故障诊断和问题排查更容易。

## 适用场景

项目非常适合以下场景：

- 教室灯光管理
- 会议室分区控制
- 多区域照明集中管理
- 需要自动恢复与远程诊断的设施控制场景
- 需要长期稳定运行且不易维护的智能控制设备

## 系统特点

### 可靠性

本项目强调“稳定运行”，不是只追求功能实现，而是让功能在真实环境中持续可用。

### 安全性

在故障、断电、网络异常或启动异常的情况下，系统会优先进入安全状态，以防止灯光状态失控。

### 可维护性

日志、状态恢复、升级与异常处理的设计，帮助运维人员更快发现问题并恢复设备。

### 可扩展性

项目结构适合后续增加更多控制策略、设备功能和更丰富的管理能力。

## 使用方式

项目适合用于智能照明控制设备的现场部署与管理。使用时一般分为以下几步：

1. 硬件部署：将控制器接入灯光回路和现场按键。
2. 设备启动：系统自动完成状态检查与初始化。
3. 网络连接：设备会尝试连接到可用网络环境并建立通信链路。
4. 控制使用：可通过现场按键和远程控制平台发出指令。
5. 状态监控：控制器会持续保持状态同步并记录关键事件。
6. 维护升级：根据需要进行在线更新和异常恢复。

## 设计理念

Light-Control 的核心设计理念是：

- 让设备不仅“能控制”，而且“能持续可靠地工作”；
- 让普通用户可以方便地使用，但对维护人员也保留足够的诊断和修复能力；
- 让系统面对网络切换、异常重启和现场环境变化时具备主动适应能力。
